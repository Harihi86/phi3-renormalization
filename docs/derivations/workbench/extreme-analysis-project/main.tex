\section{The common finite BPH kernel and the precision problem}
Each loop measure is $d^6k/\pi^3$; graph weights and couplings are separate. All Taylor counterterms retain their finite parts. For the standard nested triangle let $s_i=p_i^2$, $p_1+p_2+p_3=0$ and $D(r)=(r^2+M)^{-1}$. Write
\[
a=D(k)D(k+p_2)D(k-p_1),\quad h=D(q)D(q+k)D(q+k-p_1).
\]
The recursively prepared and overall-subtracted integrand is
\[
RI=a[h-D(q)^3]-D(k)^3[D(q)D(q+k)^2-D(q)^3].
\]
For the outer and inner Schwinger simplices use $(a,b,c)$ and $(u,v,w)$, respectively. With $k_0=cp_1-bp_2$, set
\[
W=ab s_2+ac s_1+bc s_3,\quad G=uv|k_0|^2+uw|k_0-p_1|^2+vw s_1.
\]
The repeated letter $a$ denotes a simplex fraction only in the parameter formulas below. The implementation separates $L=\log S-\log M$, $S=\max s_i$, before exponentiating any ratio. Thus finite physical inputs whose ratio overflows binary64 remain usable. A finite return or agreement of unresolved fixed nodes is insufficient evidence: independent parameterizations and compiled original graphs are required.
