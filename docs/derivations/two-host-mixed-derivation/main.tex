\section*{Exact local subtractions}
Let \(\ell=x(1-x)\). The complete subtracted bubble is
\[
 B(s)=\int_0^1[(1+\ell s)\log(1+\ell s)-\ell s]\,\dd x,
 \qquad B(0)=B'(0)=0.
\]
The two zero conditions encode the mass and kinetic Taylor terms.
Set \(E(s)=\int_0^1\log(1+\ell s)\,\dd x\). Then
\[
 B(s)=\frac{s+4}{6}E(s)-\frac{s}{9},\qquad
 J(s)=\frac{B(s)}{1+s}.
\]
The denominator in \(J\) is exactly one retained host propagator.
The independent reference keeps all seven original host propagators
and uses \(B\); the native kernel uses six hosts and \(J\).
This equality holds for every physical momentum, before expansion.

The complete triangle is

\section*{Absolute integrability}

\[
 0\leq B(s)\leq \frac{s\log(1+s)}6,\quad
 B'(s)\leq\frac{\log(1+s)}6,\quad B''(s)\leq\frac1{6(1+s)}.
\]
Consequently
\[
 |J_s|\leq\frac{\log(1+s)}{3(1+s)},\qquad
 |J_{ss}|\leq
 \frac{1/6+(2/3)\log(1+s)}{(1+s)^2}.
\]
For \(s=|u+\lambda p|^2, |p|\leq1,|\lambda|\leq1\), put

\(D/3\leq1+s\leq3D\), the physical derivative bounds are
\[
 |J|\leq L/3,\quad |J_\lambda|\leq3L/\sqrt D,\quad

\(M=256\log(2+\max(t,v,w))\).

\[

ordered-sector majorant \(883548\), preserving absolute integrability.
