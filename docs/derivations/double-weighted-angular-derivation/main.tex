\paragraph{Exact spherical expansion.}
For $s,t>0$, define
\[
 a=1+s+t,\quad \Delta=\sqrt{a^2-4st},\quad
 K(s,t)=\frac2{a+\Delta},\quad r(s,t)=K(s,t)\sqrt{st}.
\]
The expansion in six-dimensional zonal harmonics is
\[
 \frac1{1+s+t-2\sqrt{st}\,c}
 =\sum_{n=0}^\infty f_n(s,t)C_n^{(2)}(c),\qquad
 f_n=Kr^n\left(\frac1{n+1}-\frac{r^2}{n+3}\right).
\]
It follows from
$C_n^{(2)}-C_{n-2}^{(2)}=(n+1)C_n^{(1)}$
and the elementary generating function for $C_n^{(1)}$.
Normalized angular averages satisfy
\[
 \left\langle C_n^{(2)}(\widehat q\cdot\widehat k)
 C_m^{(2)}(\widehat k\cdot\widehat p)\right\rangle_{\widehat k}
 =\delta_{nm}\frac2{n+2}C_n^{(2)}(\widehat q\cdot\widehat p).
\]
The two signs from $q+k$ and $k+p$ cancel at each $n$. Thus,
with $e=p^2$, the full bare angular integral is
\[
 H(s,t;e)=\sum_{n=0}^\infty
 \frac{2(n+1)(n+3)}{3(n+2)}
 f_n(s,e)f_n(t,e)f_n(s,t).
\]

\paragraph{Closed summation and a separate rigorous series.}
Put $\alpha=r(s,e)^2,\ \beta=r(t,e)^2,\ \gamma=r(s,t)^2$,

\section*{A complete Hepp-sector proposal with exact probabilities}
The original eight projective charts can instead be partitioned into all
$8!$ strict orders of the eight parameters. Ties have measure zero.
For an order $(e_0,\ldots,e_7)$, put
\[
 S_j=\{e_j,\ldots,e_7\},\qquad
 \alpha_{e_0}=1,\qquad
 \alpha_{e_j}=\prod_{k=1}^{j}r_k,\qquad r_j=u_j^{p(S_j)}.
\]
The positive integer powers are fixed from the polynomial supports before
fresh diagnostics. In this implementation $p(S)$ is either 1 and 2, or
1 and 4. The support score used to choose them is
\[
 \gamma(S)=\min_{\text{paired states}}
 \bigl[|S|+2\min_{m\in\operatorname{supp}F}|S\cap m|
             -5\min_{m\in\operatorname{supp}U}|S\cap m|\bigr].
\]
The larger power is used when $\gamma(S)\leq1$.
This score only designs the proposal: it is not a convergence proof or
a finite-variance certificate for the signed forest sum.

Define exact integer weights recursively by
\[
 H(\varnothing)=1,\qquad
 H(S)=p(S)\sum_{e\in S}H(S\setminus\{e\}),\qquad
 Z=\sum_{e\in E}H(E\setminus\{e\}).
\]
The conditional probability of removing $e$ from the current set $S$ is

 \pi(e_0,\ldots,e_7)=\frac{\prod_{j=1}^{7}p(S_j)}Z.
