# Publication and migration scope

This update imports the owner's current computational implementation and
original mathematical derivations. The root MIT license covers original
software and explanations included here, not third-party references or libraries.

The import contains 55 core modules, two original exact regression suites,
326 mathematical Python modules, 168 native source/header files and 53 TeX
sources, plus a portable public entry point. Source hashes and presentation
edits are recorded in [source-import.json](source-import.json). Version labels
inside historical headers do not override content comparison. The earlier
`phi3_public` API remains compatible; `phi3lab` supplies the imported engine.

Original research files, frozen strategies and evidence are not modified by
the public import. Private correspondence, task transcripts, credentials,
SSH configuration, operational launchers, environments, native binaries,
bulk samples and private Git history are excluded. Research evidence paths are
replaced with relative record references; their hashes and scientific status
remain recorded. The ledger export is not a fresh reproduction of 162 integrals.

Fresh public examples come from documented commands. Default tests do not
run the four-loop generator or heavy integral campaigns. Research C++ sources
include historical candidates; inclusion does not mark every version accepted.
Generated graph bindings and external Boost/FLINT/Arb installations are needed
for their respective native builds and are not vendored.

The heavy Mac campaign remains paused. This repository update does not resume it.
