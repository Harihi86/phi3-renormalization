# 从生成泛函到完整反项表

[English](theory.md) · [统一约定](conventions.md) · [L2E3G4 演示](L2E3G4-zh.md)

## 1. 先计数，再区分图类

相互作用指数给出顶点种类阶乘及每个 r 价顶点的 `1/r!`，自由 Gaussian 给出半边配对。
`ct_wick.enumerate_wick` 精确记录 Wick 重数、真空分量、源直接配对及接受／排除理由。
连通、截肢和去除内部桥得到 1PI 是不同步骤；外腿标签在同构中逐点固定。
平行边和自环半边的自同构因子不能遗漏。

带符号系数由正有理组合权重乘顶点符号和耦合幂得到；`1/S` 本身不是完整振幅系数。
`ct_typed` 将同样的精确规则扩展到反项顶点种类和高圈族。

## 2. 路径 A 真正递归

`ct_bph.recursion` 从原图的发散边子集出发，生成边界端口、递归减除后的子图内部及收缩宿主，
明确记录 `C(γ)=−Tγ R̄(γ)` 和 `R(G)=(1−TG)R̄(G)`。
这不是从已完成的插入表倒推递归。相容路由区分内部和外部环基底：
Taylor 只缩放所选子图的边界依赖，宿主传播子不参与该缩放。

互不相交子图可以组成同一 spinney；嵌套反项由递归子节点产生，内投影先做。
重叠子图分别保留，不能放在同一兼容乘积中。Henge 边映射和独立森林展开用于核验递归。
`ct_series_a` 将这一表示推广到四圈。

## 3. 路径 B 从作用量重新生成

`ct_action.build_path_b()` 不接收目标图集。它按所需耦合阶枚举类型化作用量单项式，
对每种顶点组做 Wick 配对和连通／1PI 筛选，独立生成低圈局部反项来源。
反项源通过全部端口双射粘接到宿主反项顶点，再用顶点、边及半边同构映射确定原图。
端口双射数除以端口阶乘，不能再重复计入不固定外腿的对称因子。

`ct_series_b.ActionLibrary` 递归构造自己的低圈局部投影库，保存的来源引用与该库逐项比较。
输入是顶点类型、耦合阶和作用量规则，不是 A 的子图、收缩列或系数。
共享图表示与同构工具；这条独立性边界不等于另外宣称两套数值积分器完全独立。

## 4. 比较同一个数学对象

`ct_verify` 和 `ct_series_verify` 比较每格的有理算符多项式，包含结构零；
还检查图标签／类型、Taylor 次数、来源身份、半边映射与环动量基变换。
数值容差不能替代精确相等。回归测试会修改符号、重数、标签及动量映射并要求拒绝，
也会禁用 A 的生成器后重新运行 B。

最终局部列是对“裸图加低圈反项项”施加整体负投影；二点质量与动能整体列始终分别保留。
[泡插入示例](L2E3G4-zh.md)展示这些符号，并解释为什么不能将宿主环动量一起置零。

## 5. 数值层单独验收

`automatic_bph` 从图的关联关系与路由生成 Gaussian Taylor 程序；`finite` 和逐拓扑模块保留有限积分参照。
后续研究包含精确多项式绑定、径向解析积分、有理变量变换及区间原函数。
精确变量变换、单个坐标面估计、算术区间和完整积分误差界是不同结论，
当前验收见[状态记录](status.md)，不能互相替代。

保留更完整的原始论证。有限测试覆盖不构成普遍全圈定理。
