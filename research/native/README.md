# Optional generic multiprecision executor

This directory contains Phi3Lab's own C++ implementation of the compiled
recursive Gaussian BPH program. It reads every routing coefficient, scaling
monomial, Taylor order and recursive sign from `CompiledBPH.to_dict()`; it does
not select formulas by graph number or topology. The ordinary Python and
standard-library Decimal implementation remains available independently.

Build explicitly from the software root with a C++17 compiler and external
Boost headers:

```text
python3 tools/build_automatic_native.py --boost /path/containing/boost
```

`BOOST_ROOT` and `CXX` are optional alternatives. The build script never downloads
dependencies. Boost.Multiprecision's `cpp_dec_float` backend is header-only and
requires no Boost runtime library. Official documentation:
https://www.boost.org/latest/libs/multiprecision/doc/html/boost_multiprecision/tut/floats/cpp_dec_float.html

The tested build used official Boost 1.89.0. Its source archive was downloaded
only into the development `work/` directory from
https://archives.boost.io/release/1.89.0/source/boost_1_89_0.tar.bz2
and verified against the official archive metadata, SHA256
`85a33fa22621b4f314f8e85e1a5e2a9363d22e4f4992925d4bb3bc631b5a0c7a`.
No Boost header tree is copied into this release.

The optional binary in `build/` is host-specific and compiled from the included
Phi3Lab source. It is separate from official pySecDec's native reference
libraries; those upstream generated libraries are not redistributed here.
`automatic_native_build.json` records the compiler, host, command, source hash,
binary hash and build duration. Loading requires the current platform/CPU,
ABI, C++ source hash and binary hash to match. Cached handles are checked again
on subsequent calls. A changed library is never hot-reloaded into an existing
process; restart after rebuilding.

`try_native_batch_density` returns `None` when unavailable, permitting the caller
to continue with Decimal without recursion. `native_batch_density` offers that
Decimal fallback directly. `PHI3LAB_DISABLE_NATIVE=1` disables the optional path
even if a library was already cached, for reproducible independent Python checks.
For batches of at least 64 points the default is up to four standard C++ threads;
smaller batches use one. `PHI3LAB_NATIVE_THREADS=1` forces serial execution, or
set an integer from 1 to 64. Program/layout data are immutable and error messages
are thread-local, so two application requests may safely share a prepared handle.

Each accepted native point has been calculated independently at 50 and 100
decimal digits, compared at relative tolerance `1e-25`, and checked using the
sum of absolute Taylor coefficients. Unstable points are returned to adaptive
Decimal rather than accepted. The two stable radial series stop according to
the active arithmetic precision, never a fixed term count. These are numerical
precision diagnostics, not rigorous rounding or quadrature error intervals.
Binary64 underflow is flagged separately; `density_text(..., digits=100)` retains
the unrounded multiprecision value for verification.
